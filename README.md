# ALL TALENTS Agency — Platform

Private celebrity representation & strategic bookings platform.

## Local Development

```bash
npm install
npm run dev
```

- Website: http://localhost:5600  
- API: http://localhost:4100/api/health

## Environment Variables

Copy `api/.env.example` to `api/.env` and fill in values before deploying.

## Structure

```
website/          Static front-end (HTML/CSS/JS)
api/src/server.js Express API
api/src/data.js   In-memory data layer
```
